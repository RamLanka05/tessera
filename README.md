# tessera - Distributed Configuration Server

## About

A production-grade configuration management server built in Go. Provides multi-version config storage, JWT authentication, and instant rollback capabilities through a React admin dashboard.

## Tech Stack

- **Backend:** Go, PostgreSQL, JWT (RS256)
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **DevOps:** Docker, Docker Compose, GitHub Actions, Makefile
- **Database:** PostgreSQL with transactional safety
